This repo is used for my website https://theorem-marketplace.com as a simple API to verify if a given string is a valid proof for a given theorem in Lean. 

It works together with the main theorem-marketplace repo. It just runs SafeVerify, periodically checking for updates etc. You need to have lean and lake installed etc.

Kudos to [GasStationManager](https://github.com/GasStationManager) for creating [SafeVerify](https://github.com/GasStationManager/SafeVerify) which this repo uses.
